# Live-Betrieb

Die Anwendung wird aus dem privaten GitHub-Repository veröffentlicht. D1 hält
die Geschäftsdaten, R2 die hochgeladenen Dateien und erzeugten Belege. Der
Nginx-Server unter `v2202608397611499388.supersrv.de` dient als Reverse Proxy
vor der veröffentlichten Anwendung.

Die produktive Nginx-Konfiguration liegt in `nginx-printcenter.conf`.
